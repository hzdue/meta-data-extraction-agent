# 600 Papers with Gemma 31B Zero-Shot Predictions

This dataset contains 600 scientific papers related to photon and neutron
experiments, together with the available schema-guided metadata predictions
generated by `google/gemma-4-31B-it`.

## Contents

```text
share_600_papers/
├── README.md
├── manifest.jsonl
├── schemas/
│   ├── generic.json
│   └── photon_and_neutron.json
└── papers/
    └── <paper_id>/
        ├── paper.pdf
        └── global_seed_prediction.json
```

There are **600 PDF files and 595 prediction files**. The five papers listed
below have a PDF but no saved prediction. Their manifest entries explicitly
mark the prediction as missing; no placeholder prediction is supplied.

- `2106.09774`
- `2312.15028`
- `2504.16653`
- `2506.18730`
- `2601.06716`

Of the 595 prediction files, 591 are unchanged copies of saved JSON files.
The other four were exported from existing saved seed records without changing
their field values: `1803.02244`, `1806.09416`, `2010.12357`, and `2404.18915`.

## Files and fields

- `paper.pdf`: the source paper, identified by its arXiv ID.
- `global_seed_prediction.json`: the original structured extraction, before
  subsequent corrections. It contains `bibliographic`, `document_overview`,
  `facilities`, `samples`, and `datasets`.
- `schemas/generic.json`: definitions and instructions for bibliographic and
  document-level metadata.
- `schemas/photon_and_neutron.json`: definitions and instructions for
  facilities, samples, datasets, and their references.
- `manifest.jsonl`: one UTF-8 JSON object per paper. Each entry records the
  paper ID, title, publication date, subject group, page count, relative file
  paths, byte sizes, SHA-256 hashes, prediction availability and provenance,
  model identifier/revision, and schema paths/hashes.

All paths in the manifest are relative to this folder. Prediction status is
`available`, `recovered_saved_seed`, or `missing`. Status describes file
availability, not the scientific accuracy of a prediction.

## Prediction source

- Model: `google/gemma-4-31B-it` (31B).
- Model revision: `842da3794eaa0b77d5f08bae87a17459d91ff475`.
- Extraction mode: zero-shot, with the extraction instructions, schema and
  paper text provided without few-shot demonstrations.
- Sampling temperature: `0`.

The JSON files are saved structured predictions, with their existing parsing
and normalization preserved; they are not verbatim model response strings.
They are model-generated labels, **not human-annotated ground truth**.

## Using the data

For supervised fine-tuning, use a paper's text and the relevant extraction
instructions/schema as input and its available JSON prediction as the target.
There are 595 available paper/prediction pairs. Missing predictions must not be
treated as empty extraction answers.

To inspect the manifest with Python:

```python
import json
from pathlib import Path

root = Path("share_600_papers")
with (root / "manifest.jsonl").open(encoding="utf-8") as stream:
    papers = [json.loads(line) for line in stream if line.strip()]

pairs = [row for row in papers if row["global_seed_prediction"]["path"] is not None]
print(f"Papers: {len(papers)}; available prediction pairs: {len(pairs)}")
```
